

# Wasteful

The official website for **Wasteful**, a simple bin collection reminder app.

Wasteful helps you keep track of your bin collection schedules and reminds you when it's time to put your bins out.

## Features

- Find your local council
- Add bin collection schedules
- Choose collection days and repeat intervals
- Set reminder preferences
- Manage multiple addresses and schedules
- Track upcoming collections
- Mark collections as taken out
- Local notifications

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Development

Clone the repository:

```bash
git clone <your-repository-url>
cd <your-repository-name>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
